# Computational Methods in Engineering

A collection of Python projects developed throughout a Computational Methods in Engineering course.

This repository focuses on numerical methods, scientific computing, and computational engineering applications.

## Projects

### 01. Transient 1D Heat Conduction

**Methods:** Finite Volume Method (FVM), Fully Implicit Time Integration, and Tri-Diagonal Matrix Algorithm (TDMA).

Numerical solution of a one-dimensional transient heat conduction problem, including comparison with an analytical Fourier series solution and numerical error analysis.
